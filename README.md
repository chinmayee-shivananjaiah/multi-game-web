# multi-game-web
A web-based multi-game application featuring Tic-Tac-Toe, Connect Four, and Rock-Paper-Scissors with interactive gameplay.
Multi-Game Web App

A web-based collection of classic games featuring interactive gameplay and a simple, user-friendly interface.

Games Included

-  Tic-Tac-Toe
-  Connect Four
-  Rock-Paper-Scissors

Features

- Interactive gameplay
- Simple and responsive interface
- Multiple classic games in one application
- Easy navigation between games
- Player-friendly design

Technologies Used

- HTML
- CSS
- JavaScript

How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in a web browser.
4. Select a game and start playing.

Project Structure

Multi-Game-Web-App/
│
├── index.html

Output

The application provides a web interface where users can select and play different classic games.
